# GLORIA_db

This folder holds the main MRIO data, this is by default the GLORIA database or an extract of the GLORIA database. Due to restrictions of the use of the GLORIA database, we are unable to provide a copy of the database in this repository.

Please see https://ielab.info/labs/ielab-gloria for further access and further details.

GLORIA has been created in the Global MRIO Lab – a branch of the NeCTAR Industrial Ecology Virtual Laboratories (IELabs, NeCTAR 2013; Lenzen et al. 2014a; Geschke and Hadjikakou 2017) – by a collaboration between the University of Sydney, the CSIRO, Wirtschafts-Universität Wien, and UNSW Sydney.
